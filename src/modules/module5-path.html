🎯 小挑战：从左上角走到右下角，只能向右或向下，一个 3×3 的格子共有多少条最短路径？
1
第一行和第一列全部填 1（只有一种走法，一直往右或一直往下）
2
逐格填写：每格 = 上方格数 + 左方格数
第2行第2格 = 1+1 = 2；第2行第3格 = 1+2 = 3
3
右下角就是答案：1,1,1 / 1,2,3 / 1,3,6 → 共 6 条最短路径 ✅
🧭
方向转换口诀法
面朝不同方向，左右东西会互换！
⌄
🎯 小挑战：小明面朝南站立，他的右手边是哪个方向？
1
画出方向图：地图上北上南下，东右西左（这是地图视角）
2
小明面朝南（背朝北）→ 他的前方是南，后方是北
3
面朝南时：右手边 = 西（东西互换了！）✅ 口诀："面南背北，左东右西"

走迷宫 · 右手法则
右手始终贴着右侧墙壁走，一定能走出去！
⌄
🎯 挑战：遇到复杂迷宫，怎样保证一定能走出去，不会原地打转？
1
右手法则：进入迷宫后，右手始终保持贴着右边的墙壁行走
2
遇到岔路：优先向右转；右边是墙就直走；直走也是墙就向左；全堵就掉头
3
科学原理：对于与外墙连通的迷宫，右手法则100%有效！适合没有"环形"路段的迷宫 ✅
📝 例题一：最短路径数
从 A 点出发，只能向右或向下行走，到达 B 点共有多少条最短路径？
A 在左上角，B 在右下角，格子是 3列×2行（即需要向右走2步，向下走1步）。
💭最短路径需要走几步？向右几步，向下几步？▼
向右 2步，向下 1步，总共走 3 步。最短路径每次走法都是恰好 3 步！
💭用加法规则填格子：第一行和第一列怎么填？▼
第一行：1,1,1（一直向右，只有1种走法）
第一列：1,1（一直向下，只有1种走法）
💭第2行第2格和第2行第3格各是多少？▼
第2行第2格 = 上1 + 左1 = 2
第2行第3格（即B点）= 上1 + 左2 = 3 条路径 ✅
🧠 费曼讲解：为什么是3条？
1
每条路都要走 右右下 或 右下右 或 下右右 其中一种组合
2
2个"右"和1个"下"的排列数 = 3 ÷ 1 × (3-1) = 3种（把"下"放在第1、2、3步中选一个位置）
3
加法规则其实是这个排列计算的快捷版！填格子就是在积累所有路径 🎉
📝 例题二：方向判断
小美站在学校门口，学校在她的正东方，图书馆在她的正南方。
请问：图书馆在学校的哪个方向？
💭小美、学校、图书馆分别在哪里？先画出位置！▼
小美站在中间。学校在小美的正东方（右边）。图书馆在小美的正南方（下面）。
💭以学校为中心，图书馆在哪个方向？▼
以学校为中心：图书馆在学校的西边（因为学校在小美右边，图书馆在小美下面，相对学校而言，图书馆在西南）。
💭为什么是西南方，而不是南方？▼
图书馆在学校的左边（西方）且下边（南方），所以合起来是西南方！✅
🧠 费曼讲解：方向推理三步走
1
先画位置图：把所有地点画在格子里，这样眼睛能直接看出方向
2
换主角视角：把"问谁的方向"那个地点当做中心，重新看其他地点在哪里
3
合并方向：如果既偏西又偏南，就是西南；既偏东又偏北，就是东北 🎉
📝 例题三：迷宫路径计数
一个迷宫，从入口到出口只有一条通路（没有环路）。小明走了15步到达出口，小红走了18步，小蓝走了15步。
以下哪个说法是正确的？
💭题目说"只有一条通路"，这意味着什么？▼
只有一条通路说明：所有人走的路线完全相同，只是步数可能不同（有人走了弯路/重复路）。
💭步数最少的是谁？多走的步数去哪了？▼
小明和小蓝都走了 15步，最少。小红走了18步，多出3步说明走了重复路段（来回走了某段路）。
💭小明和小蓝都走了15步，他们的路线一样吗？▼
因为只有一条通路，路线是唯一的！步数相同（都是15步，没有重复走）说明他们走了同一条路 ✅
🧠 费曼讲解：唯一通路的奥秘
1
唯一通路意味着路线没有分叉，所有人都走同一条路（不可能走不同路线）
2
步数差异的原因只有一个：有人在某处来回走了（多走 2n 步）
3
步数最少 = 没有来回 = 最短路径；同步数同路线，不同步数说明有人迷路了 🎉
